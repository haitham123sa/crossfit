## Remaining steps before enabling Facebook

1. **Meta icon:** Upload the downloaded 1024×1024 icon and save.
2. **Facebook/Firebase identity match:** In [Firebase Authentication](https://console.firebase.google.com/project/h-forge/authentication/providers), open the Facebook provider and check whether its public App ID is **1154248590649927**. If different, go to the corresponding H-FORGE [Meta developer app](https://developers.facebook.com/apps/1154248590649927/) and securely enter the new app's **App ID and App Secret** in Firebase. **Never paste the App Secret into chat or GitHub.**
3. **Meta public launch:** In Meta for Developers, complete any remaining app review, data/privacy or verification requirements and switch H-FORGE to **Live** if eligible. Basic `public_profile` and `email` may be handled differently depending on Meta's use case and review requirements.
4. **Test:** Using the intended Facebook app, test Facebook Login against Firebase (ideally in Safari on iPhone) and confirm existing email/Google users can link without changing their Firebase UID or losing PRs.
5. **Website activation:** Only after those tests pass, change `window.HFORGE_FACEBOOK_READY=false` to `true` in `firebase-config.js`, bump its script URL and service-worker cache, and deploy via GitHub Pages.

H-FORGE's account-deletion control is under **Settings → Account & Cloud Sync → Delete account & cloud PRs**. It deletes the user's Firestore profile and Firebase Authentication account, with explicit confirmation. If Firebase requires a recent login, retry after signing in again. Backups and browser caches on other devices must be removed separately. The privacy and deletion pages should be reviewed by the app owner for legal and policy accuracy before widespread promotion.

## Cost and security

Stay on **Firebase Spark with no billing account**, do not pay for a Meta upgrade, and do not use paid products. Never put a Meta App Secret in the public web app, GitHub repository or chat. The app uses Facebook Login via Firebase and only basic identity permissions; no marketing/friends permissions are requested.
